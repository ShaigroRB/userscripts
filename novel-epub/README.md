# novel-epub

Userscripts that capture web novel and light novel chapters as you read and export them as EPUB files.

Everything runs in your browser: chapters are saved by your userscript manager as you read, and the EPUB is built locally. No server or extra tools needed.

## Supported websites

| Website                                    | Script                                       | Status                                                           |
| ------------------------------------------ | -------------------------------------------- | ---------------------------------------------------------------- |
| [webnovel.com](https://www.webnovel.com)   | [`webnovel.user.js`](webnovel.user.js)       | ☑️                                                               |
| [novelsworld.org](https://novelsworld.org) | [`novelsworld.user.js`](novelsworld.user.js) | ☑️                                                               |
| [utoon.net](https://utoon.net)             | [`utoon.user.js`](utoon.user.js)             | Archived: no longer a light novel platform. Kept as a reference. |

## Notes

- Only chapters you can read in the browser are captured. Locked or paid chapters are skipped, and auto-advance stops on them.
